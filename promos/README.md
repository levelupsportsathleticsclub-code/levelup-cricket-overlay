# LevelUp sports promos for OBS

Add a separate Browser source for each link, with Local file off and the Browser source matching the OBS canvas (for example, 1920 × 1080). The graphics use a transparent full canvas with a fixed lower-third banner. Toggle sources with the eye icon. Keep one promo visible at a time. Turn it off while the cricket scoreboard is visible because both occupy the bottom of the frame.

Base URL: https://levelupsportsathleticsclub-code.github.io/levelup-cricket-overlay/promos/
